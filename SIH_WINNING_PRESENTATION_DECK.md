## 🎨 MASTER VISUAL DESIGN SYSTEM (How to Make it Look "Top-Notch")

### 1. Visual Hierarchy & Color Palette
* **Primary Accent (Navy/Steel Blue)**: `#0F2B48` — Conveys enterprise industrial trust, government sovereignty, and defense-grade engineering.
* **Secondary Accent (Cyber Teal / Cyan)**: `#00A896` / `#028090` — Used for AI/ML neural pipeline nodes, flow arrows, and active features.
* **Alert / Warning (Coral Red / Amber)**: `#E63946` / `#F4A261` — Used for "Problem at Hand", pain-point metrics, and failure detection.
* **Success / Grounding Green**: `#2A9D8F` — Used for "100% Verified", "Zero Egress", "Tamper-Evident", and ROI metrics.
* **Backgrounds & Cards**: Pure crisp white `#FFFFFF` cards set against `#F8F9FA` ultra-light gray slide canvas with `1.5px` rounded borders and subtle drop shadows (`0 4px 12px rgba(0,0,0,0.06)`).

### 2. Layout Structure Rules (Learned from Winning Decks)
* **Never use plain bulleted text walls**: Every slide must follow a **multi-column bento-grid** (cards, comparison tables, process flows, callout metric badges).
* **Metric Callouts**: Always bold quantitative metrics (`65 tokens/sec`, `1GB limit`, `₹0 API cost`, `100% On-Device`, `0 Bytes Egress`).
* **Visual Anchors**: Each slide must have a dedicated hero visual (e.g., Slide 2: UI/Deliverable mockup; Slide 3: End-to-end architecture schematic; Slide 4: Economic comparative table).
